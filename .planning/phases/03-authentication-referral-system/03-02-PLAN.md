<task id="03-02-03" wave="1">
<title>Реализация сервисного слоя AuthService с транзакциями</title>
<instruction>
1. Создать `backend/internal/service/auth.go`:
   - Структура `VKProfile`: `ID int64`, `FirstName string`, `LastName string`, `AvatarURL string`.
   - Структура `UserDTO`: `ID int64`, `VKID int64`, `FirstName string`, `LastName string`, `AvatarURL string`, `RefCode string`, `RefLink string`, `BalanceRub float64`, `BalanceKopecks int64`.
   - Интерфейс `AuthService`:
     - `AuthenticateOrRegister(ctx context.Context, profile VKProfile, refCode string) (*model.User, error)`
     - `GetProfile(ctx context.Context, userID int64) (*UserDTO, error)`
   - Реализация `authService`:
     - Зависимости: `userRepo`, `balanceRepo`, `referralRepo`, `txManager`, `refGen`, `frontendURL`.
     - Метод `AuthenticateOrRegister`:
       - Проверяет существование пользователя по `profile.ID` (`GetByVKID`).
       - Если пользователь существует: обновляет поля профиля при необходимости и возвращает его.
       - Если пользователь новый: вызывает `txManager.WithinTransaction`:
         1. Если `refCode != ""`, ищет реферера через `userRepo.GetByRefCode`.
         2. Генерирует уникальный `ref_code` через `refGen`.
         3. Вставляет нового пользователя в `users` с `referred_by = referrerID`.
         4. Начисляет приветственный бонус: `balanceRepo.AddBonus(txCtx, newUser.ID, model.WelcomeBonusKopecks, model.TxWelcomeBonus, nil, "Приветственный бонус при регистрации")`.
         5. Если валидный реферер найден и `referrerID != newUser.ID`:
            - Записывает связь через `referralRepo.Create(txCtx, referrerID, newUser.ID, model.ReferralRewardKopecks)`.
            - Начисляет вознаграждение рефереру: `balanceRepo.AddBonus(txCtx, referrerID, model.ReferralRewardKopecks, model.TxReferralReward, &refereeIDStr, "Реферальное вознаграждение")`.
     - Метод `GetProfile`:
       - Получает пользователя по `userID`.
       - Получает баланс по `userID` (если не найден — 0).
       - Формирует `UserDTO` с расчётом `BalanceRub = float64(AmountKopecks) / 100.0` и `RefLink = fmt.Sprintf("%s/?ref=%s", frontendURL, user.RefCode)`.
2. Создать `backend/internal/service/auth_test.go`:
   - Тест первичной регистрации нового пользователя (проверка создания пользователя, баланса 500 копеек и проводки welcome_bonus).
   - Тест регистрации по валидному реферальному коду (проверка начисления 200 копеек рефереру и 500 копеек новичку).
   - Тест повторного входа существующего пользователя (проверка неизменности баланса и отсутствия лишних транзакций).
   - Тест регистрации с невалидным ref_code (проходит штатно без начисления рефереру).
   - Тест защиты от само-реферала.
</instruction>
