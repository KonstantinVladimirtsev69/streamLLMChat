<task id="03-03-01" wave="2">
<title>Реализация клиента VK OAuth 2.0 и Mock провайдера</title>
<instruction>
1. Создать `backend/internal/auth/vk.go`:
   - Структура конфигурации `VKConfig`: `ClientID string`, `ClientSecret string`, `RedirectURI string`, `FrontendURL string`, `MockAuth bool`.
   - Интерфейс `VKOAuthClient`:
     - `GetAuthURL(state string) string`
     - `ExchangeCode(ctx context.Context, code string) (*VKProfile, error)`
   - Реализация `vkOAuthClient`:
     - `GetAuthURL`: формирует ссылку на `https://oauth.vk.ru/authorize` с параметрами `client_id`, `redirect_uri`, `response_type=code`, `v=5.131`, `state` (поддерживает переопределение через `VKConfig.BaseURL`).
     - `ExchangeCode`: выполняет POST/GET к `https://oauth.vk.ru/access_token`, получает `access_token` и `user_id`, затем вызывает `https://api.vk.ru/method/users.get?v=5.131&fields=photo_200`, возвращает `VKProfile`.
   - Реализация Mock-клиента `mockOAuthClient` для тестов и локального запуска: возвращает фиктивный профиль при вызове `ExchangeCode`.
2. Создать `backend/internal/auth/vk_test.go`:
   - Тест формирования URL авторизации.
   - Тест обмена кода через `httptest.Server`.
</instruction>

<task id="03-03-02" wave="2">
<title>Реализация HTTP-хэндлеров аутентификации</title>
<instruction>
1. Создать `backend/internal/server/handler/auth.go`:
   - Конструктор `NewAuthHandler(authService service.AuthService, vkClient auth.VKOAuthClient, tokenManager auth.TokenManager, cfg AuthHandlerConfig) *AuthHandler`.
   - Конфигурация `AuthHandlerConfig`: `CookieDomain string`, `CookieSecure bool`, `FrontendURL string`, `SessionTTL time.Duration`.
   - Метод `Login(w http.ResponseWriter, r *http.Request)`:
     - Извлекает опциональный `ref` и `return_to` из query params.
     - Генерирует криптографический `state` и сохраняет во временную cookie `oauth_state` (HttpOnly, TTL=10 мин) упакованный JSON или токен с `ref` и `return_to`.
     - Если включен mock-режим: редиректит на `/api/v1/auth/mock?ref=...&return_to=...`.
     - Иначе: редиректит на `vkClient.GetAuthURL(state)`.
   - Метод `Callback(w http.ResponseWriter, r *http.Request)`:
     - Сверяет параметр `state` из query с cookie `oauth_state`. При несовпадении редиректит на `${FrontendURL}/?error=invalid_state`.
     - Извлекает `code`, вызывает `vkClient.ExchangeCode`.
     - Вызывает `authService.AuthenticateOrRegister(r.Context(), *profile, refCode)`.
     - Генерирует JWT токен через `tokenManager.GenerateToken(user.ID, user.VKID, sessionTTL)`.
     - Выставляет cookie `auth_token` (`HttpOnly=true`, `SameSite=Lax`, `Path=/`, `Max-Age=sessionTTL`, `Secure=cfg.CookieSecure`).
     - Очищает `oauth_state` cookie.
     - Редиректит на целевой URL (по умолчанию `${FrontendURL}/chat`).
   - Метод `MockLogin(w http.ResponseWriter, r *http.Request)`:
     - Доступен если `cfg.MockAuth == true` или dev-режим.
     - Позволяет указать `?vk_id=...&name=...&ref=...`.
     - Регистрирует/авторизует пользователя, выставляет cookie `auth_token` и перенаправляет на `/chat`.
   - Метод `Me(w http.ResponseWriter, r *http.Request)`:
     - Защищён `AuthMiddleware`.
     - Извлекает `userID` из `r.Context()`.
     - Вызывает `authService.GetProfile(r.Context(), userID)`.
     - Возвращает JSON `UserDTO`.
   - Метод `Logout(w http.ResponseWriter, r *http.Request)`:
     - Очищает cookie `auth_token` (`Max-Age=-1`, `Value=""`).
     - Возвращает JSON `{"status": "ok"}` со статусом 200 OK.
2. Создать `backend/internal/server/handler/auth_test.go`:
   - Тесты всех пяти эндпоинтов с использованием `httptest.NewRecorder` и `httptest.NewRequest`.
</instruction>
