<task id="03-01-02" wave="1">
<title>Реализация сессионного контекста и Auth Middleware</title>
<instruction>
1. Создать `backend/internal/server/middleware/auth.go`:
   - Приватный тип ключа контекста `userContextKey struct{}`.
   - Функция `WithUserID(ctx context.Context, userID int64) context.Context`.
   - Экспортируемая функция `UserIDFromContext(ctx context.Context) (int64, bool)`.
   - Функция `AuthMiddleware(tokenManager auth.TokenManager) func(http.Handler) http.Handler`:
     - Извлекает токен из cookie `auth_token`.
     - Если cookie нет, проверяет заголовок `Authorization: Bearer <token>`.
     - Если токен не найден или невалиден — возвращает JSON `{"error": "unauthorized"}` со статусом 401 Unauthorized.
     - При валидном токене помещает `claims.UserID` в контекст запроса и вызывает `next.ServeHTTP`.
2. Создать `backend/internal/server/middleware/auth_test.go`:
   - Тест успешного прохождения с валидной cookie.
   - Тест успешного прохождения с валидным Bearer заголовком.
   - Тест отказа 401 при отсутствии токена.
   - Тест отказа 401 при повреждённом/истёкшем токене.
</instruction>
