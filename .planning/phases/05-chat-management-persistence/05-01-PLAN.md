<task id="05-01-02" wave="1">
<title>Реализация ChatService с проверкой прав владения и каскадным удалением</title>
<action>
1. Создать `backend/internal/service/chat.go`:
   - Определить интерфейс `ChatService`:
     ```go
     type ChatService interface {
         CreateChat(ctx context.Context, userID int64, title, model string) (*model.Chat, error)
         ListChats(ctx context.Context, userID int64, limit, offset int64) ([]model.Chat, error)
         GetChat(ctx context.Context, chatID bson.ObjectID, userID int64) (*model.Chat, error)
         UpdateChatTitle(ctx context.Context, chatID bson.ObjectID, userID int64, title string) (*model.Chat, error)
         DeleteChat(ctx context.Context, chatID bson.ObjectID, userID int64) error
         ListMessages(ctx context.Context, chatID bson.ObjectID, userID int64, limit, offset int64) ([]model.Message, error)
         TouchChat(ctx context.Context, chatID bson.ObjectID, userID int64, model string) error
     }
     ```
   - Создать структуру `chatService` с полями `chatRepo repository.ChatRepository` и `messageRepo repository.MessageRepository`.
   - Реализовать `CreateChat`: если `title` пустой, установить дефолтное название «Новый диалог». Если `model` пустая, установить «gpt-4o-mini» (или дефолтную модель).
   - Реализовать `GetChat`, `UpdateChatTitle`: гарантируют проверку `userID`. Если не найдено или чужой — возвращают `model.ErrNotFound`.
   - Реализовать `DeleteChat`: сначала вызывает `chatRepo.Delete(ctx, chatID, userID)`. Если возвращен `model.ErrNotFound`, вернуть его. При успехе каскадно вызывает `messageRepo.DeleteByChatID(ctx, chatID)`.
   - Реализовать `ListMessages`: сначала вызывает `chatRepo.GetByID(ctx, chatID, userID)` для проверки прав доступа (возвращает `model.ErrNotFound` для чужих чатов), затем возвращает `messageRepo.ListByChatID(ctx, chatID, limit, offset)`.
2. Создать `backend/internal/service/chat_test.go`:
   - Написать модульные тесты для `ChatService` с mock-репозиториями.
   - Проверить создание чата с дефолтными значениями.
   - Проверить возврат `model.ErrNotFound` при попытке доступа к чужому чату.
   - Проверить каскадное удаление (вызов `DeleteByChatID` после успешного `Delete` чата).
</action>

<task id="05-01-03" wave="1">
<title>HTTP обработчики диалогов, маршрутизация и интеграция в main.go</title>
<action>
1. В `backend/internal/server/handler/chat.go`:
   - Добавить поле `chatSvc service.ChatService` в `ChatHandler` и обновить конструктор `NewChatHandler(provider llm.Provider, modelCache *llm.ModelCache, billingSvc service.BillingService, chatSvc service.ChatService)`.
   - Реализовать методы:
     - `CreateChat(w http.ResponseWriter, r *http.Request)`: принимает JSON `{"title": "...", "model": "..."}`, вызывает `chatSvc.CreateChat`, возвращает HTTP 201 Created.
     - `ListChats(w http.ResponseWriter, r *http.Request)`: парсит query-параметры `limit` и `offset`, вызывает `chatSvc.ListChats`, возвращает JSON `{"chats": [...]}`.
     - `GetChat(w http.ResponseWriter, r *http.Request)`: парсит `{id}` из chi URL param, вызывает `chatSvc.GetChat`. При `model.ErrNotFound` возвращает HTTP 404.
     - `UpdateChatTitle(w http.ResponseWriter, r *http.Request)`: парсит `{id}`, принимает JSON `{"title": "..."}`, вызывает `chatSvc.UpdateChatTitle`. При ошибке или невалидном title возвращает 400/404.
     - `DeleteChat(w http.ResponseWriter, r *http.Request)`: парсит `{id}`, вызывает `chatSvc.DeleteChat`. Возвращает HTTP 204 No Content или 404.
     - `ListMessages(w http.ResponseWriter, r *http.Request)`: парсит `{id}`, query-параметры `limit` и `offset`, вызывает `chatSvc.ListMessages`, возвращает JSON `{"messages": [...]}`.
2. В `backend/internal/server/server.go`:
   - В методе `RegisterChatRoutes(h *handler.ChatHandler, tokenManager auth.TokenManager)` (или расширении `RegisterLLMRoutes`):
     - Зарегистрировать защищенную группу `/api/v1/chats`:
       - `POST /` -> `h.CreateChat`
       - `GET /` -> `h.ListChats`
       - `GET /{id}` -> `h.GetChat`
       - `PATCH /{id}` -> `h.UpdateChatTitle`
       - `DELETE /{id}` -> `h.DeleteChat`
       - `GET /{id}/messages` -> `h.ListMessages`
3. В `backend/main.go`:
   - При наличии `mongoClient` инициализировать `chatRepo := mongodb.NewChatRepository(mongoClient.Database(dbName))` и `msgRepo := mongodb.NewMessageRepository(mongoClient.Database(dbName))`.
   - Инициализировать `chatService := service.NewChatService(chatRepo, msgRepo)`.
   - Передать `chatService` в `handler.NewChatHandler` и зарегистрировать маршруты чатов.
4. Обновить и расширить тесты в `backend/internal/server/handler/chat_test.go` и `backend/internal/server/server_test.go`.
