## 1. Summary of Changes

Реализована система отображения и защиты баланса, модальное окно реферальной программы и проведена сквозная сборка фронтенда:
1. **Интерактивный чип баланса (`BalanceChip.tsx`)**:
   - Отображение текущего баланса в формате `0.00 ₽` с иконкой `Wallet` в компоненте `Header`.
   - Автоматическая смена стиля на предупреждающий янтарный цвет с иконкой `AlertCircle` при балансе `<= 0.00 ₽`.
   - Клик по чипу открывает модальное окно реферальной программы для получения бонусов.
2. **Блокировка отправки сообщений (`ZeroBalanceAlert.tsx` & `ChatInput.tsx`)**:

3. **Модальное окно рефералов (`ReferralModal.tsx`)**:
   - Презентация условий: +2.00 ₽ на баланс за каждого приглашенного пользователя.
   - Поле с персональной реферальной ссылкой `?ref=<referral_code>` и кнопкой копирования с анимацией подтверждения (`✓ Скопировано!`).
   - Карточки статистики: количество приглашенных друзей и сумма заработанных бонусов.
   - Подключение в `ChatLayout` с поддержкой закрытия по клику на фон или клавише Escape.
4. **Сквозная валидация сборки**:
   - Проверка типов `npx tsc --noEmit` — 0 ошибок.
   - Сборка production bundle `npm run build` — успешно скомпилированы маршруты `/` и `/chat`.
