## 1. Summary of Changes

Реализовано полнофункциональное окно переписки с потоковым выводом SSE, подсветкой синтаксиса и селектором моделей:
1. **Потоковый SSE-клиент (`useChatStream.ts`)**:
   - Чтение потока через нативный `fetch` и `ReadableStreamDefaultReader` с `TextDecoder`.
   - Построчный буферный парсер SSE-чанков `data: {...}` с обработкой событий `delta`, `done`, `error`.
   - Поддержка немедленной остановки генерации через `AbortController` (кнопка остановки и cleanup при unmount).
   - Автоматическое создание чата при первом сообщении, если активный чат не был выбран.
   - Мгновенное списание локального баланса при событии `done` по `usage.cost_kopecks` и фоновое обновление профиля.
2. **Рендеринг сообщений и подсветка кода**:
   - `CodeBlock.tsx`: подсветка синтаксиса с помощью `react-syntax-highlighter` (PrismJS, тема OneDark), заголовок с названием языка и кнопка копирования со сменой иконки на чекмарк на 2 секунды.
   - `MessageItem.tsx`: рендеринг Markdown через `react-markdown` + `remark-gfm` в строгом AST-режиме (без `rehype-raw` для защиты от XSS). Бейджи стоимости ответа модели в рублях (`formatKopecks`) и мигающий курсор при стриминге.
   - `ChatWindow.tsx`: лента сообщений с автоматической плавной прокруткой вниз и приветственными карточками промптов для пустого диалога.
   - `ChatInput.tsx`: многострочный ввод с автоподбором высоты, отправка по Enter (Shift+Enter для переноса), динамическая трансформация кнопки Send в красную кнопку Abort во время стриминга.
3. **Каталог и выбор моделей**:
   - `ModelSelector.tsx`: загрузка списка моделей из `/api/v1/models`, дропдаун с быстрым поиском, отображением контекста (в токенах) и переключением активной модели.
   - `Header.tsx`: компонент шапки с адаптивной кнопкой мобильного меню, заголовком активного диалога и слотом для селектора моделей и баланса.
   - `frontend/src/app/chat/page.tsx`: сборка рабочей области диалога с загрузкой истории (`GET /api/v1/chats/{id}/messages`).
