## 1. Executive Summary

Фаза 6 реализует клиентский интерфейс сервиса на Next.js, соединяющий все разработанные серверные подсистемы (VK OAuth, биллинг в PostgreSQL, чаты в MongoDB, потоковый инференс routerai.ru):

1. **Приветственный экран и маршрутизация (UI-01, R1)**: 
   - Посадочная страница на `/` с описанием сервиса (доступ к LLM, +5.00 ₽ стартовый бонус) и кнопкой входа через VK ID. В dev-режиме доступна кнопка быстрого входа `Dev Mock` (`/api/v1/auth/mock`).
   - Серверный `middleware.ts` на базе HttpOnly cookie `auth_token`: перенаправляет неавторизованных с `/chat` на `/`, а авторизованных с `/` на `/chat`.
   - Клиентский интерцептор для обработки HTTP 401 (сброс стора и редирект).

2. **Сайдбар и управление диалогами (UI-02, R2)**:
   - Боковая панель со списком чатов из `GET /api/v1/chats` (сортировка по `updated_at`), кнопкой «Новый диалог» (`POST /api/v1/chats`) и удалением (`DELETE /api/v1/chats/{id}`).
   - Адаптивный мобильный drawer (выезжающая панель на экранах `<768px`) с кнопкой-гамбургером и закрытием по клику вне панели или выбору чата.

3. **Окно переписки, SSE стриминг и Markdown (UI-03, R3)**:
   - Клиентский SSE-стриминг через `fetch()` + `ReadableStreamDefaultReader` с декодированием чанков `data: {"type": "delta|done|error"}` и прерыванием через `AbortController`.
   - Рендеринг сообщений через `react-markdown` (v9+) + `remark-gfm` в строгом AST-режиме (без `rehype-raw` для 100% защиты от DOM XSS).
   - Подсветка синтаксиса через `react-syntax-highlighter` (PrismJS, тема OneDark) с плашкой названия языка и кнопкой «Копировать код» со сменой иконки на галочку.
   - Во время генерации кнопка отправки заменяется на «Остановить генерацию».

4. **Каталог моделей и динамический селектор (UI-04, R4)**:
   - Загрузка моделей из `GET /api/v1/models` с кэшированием на клиенте.
   - Дропдаун с поиском моделей в шапке/панели ввода с возможностью смены активной модели в открытом диалоге.

5. **Виджет баланса, блокировка ввода и реферальная программа (UI-05, R5, R6)**:
   - Отображение текущего баланса из `GET /api/v1/auth/me` в формате `0.00 ₽`.
   - При завершении ответа (`done`) — мгновенное локальное списание по `usage.cost_kopecks` + фоновый `revalidate` профиля.
   - При балансе `<= 0.00 ₽` или HTTP 402 — блокировка поля ввода с предупреждающим баннером и CTA открытия реферального окна.
   - Модальное окно реферальной программы со статистикой (+2.00 ₽ за друга) и копированием уникальной ссылки в буфер обмена.

## 2. Dependencies & Stack Compatibility

### 2.1 Анализ совместимости с React 19 и Next.js 16
В `frontend/package.json` установлены `next: "16.3.4"`, `react: "19.2.8"`, `tailwindcss: "^4"`.
Проведена проверка версий и peerDependencies:
- `zustand` (v5.0.15) — нативно поддерживает React 19, легковесный (3KB), исключает лишние ре-рендеры дерева при стриминге чанков.
- `react-markdown` (v10.1.0) — полностью совместим с React 19.
- `remark-gfm` (v4.0.1) — стандартный GFM плагин (таблицы, списки, зачеркивание).
- `react-syntax-highlighter` (v15.6.1) — имеет `peerDependencies: { react: ">= 0.14.0" }`, нативно совместим с React 19.
- `lucide-react` (v1.47.0) — современный набор иконок для Next.js / React 19.

### 2.2 Необходимые пакеты для установки в frontend/
```bash
npm install zustand react-markdown remark-gfm react-syntax-highlighter lucide-react
npm install -D @types/react-syntax-highlighter
```

## 4. Key Implementation Pitfalls & Mitigation Strategies

1. **Pitfall: Браузерный EventSource не поддерживает POST запросы с телом.**
   - *Mitigation:* Использование нативного `fetch('/api/v1/chat/stream', { method: 'POST', body: JSON.stringify(...) })` и чтение `response.body.getReader()`. Ручной разбор строк `data: ` с обработкой незавершенных чанков в буфере.

2. **Pitfall: Утечка соединений и зависшие стримы при уходе со страницы.**
   - *Mitigation:* Каждый стрим связывается с локальным инстансом `AbortController`. В хуке `useEffect` / `cleanup` вызывается `controller.abort()`, что посылает сигнал на бэкенд, где Go-хэндлер мгновенно прерывает контекст (`<-r.Context().Done()`) и сохраняет частичный ответ.

3. **Pitfall: Зависание интерфейса (UI lag) при быстром поступлении токенов.**
   - *Mitigation:* Текст ассистента аккумулируется в Zustand-сторе для конкретного потокового сообщения. Мемоизация через `React.memo` для ранее отрендеренных сообщений истории диалога.

4. **Pitfall: Потеря сессии и рассинхронизация cookie при кросс-доменных запросах.**
   - *Mitigation:* В локальной разработке и Docker Next.js проксирует запросы на бэкенд (или использует `NEXT_PUBLIC_API_URL`) с обязательным `credentials: 'include'`. Кука `auth_token` имеет `SameSite=Lax`.

5. **Pitfall: XSS-уязвимости при выводе форматированного текста.**
   - *Mitigation:* `react-markdown` работает без `rehype-raw`, преобразуя Markdown только в безопасные React-элементы.

## 5. Validation Architecture

### 5.1 Автоматизированное тестирование
- **Type Checking:** `npx tsc --noEmit` в директории `frontend/` (строгая проверка типов TypeScript, 0 ошибок).
- **Production Build:** `npm run build` в директории `frontend/` (валидация сборки страниц, App Router маршрутов и CSS).
- **Unit/Component Testing:** Проверка парсинга SSE-потока, рендеринга `CodeBlock`, поведения кнопки «Копировать» и состояния `useChatStore`.

### 5.2 Ручная верификация сценариев (UAT)
1. **Сценарий 1 (Авторизация):** Неавторизованный вход на `/` -> отображение лендинга -> клик по Dev Mock / VK -> установка куки `auth_token` -> редирект в `/chat`.
2. **Сценарий 2 (Сайдбар и сессии):** Клик «Новый диалог» -> появление диалога в списке -> ввод первого сообщения -> авто-переименование заголовка чата в сайдбаре.
3. **Сценарий 3 (Стриминг и код):** Отправка запроса с просьбой написать код -> посимвольный SSE-вывод с мигающим курсором -> рендеринг блока кода с кнопкой копирования -> клик копирования -> всплытие `✓ Скопировано!`.
4. **Сценарий 4 (Остановка стриминга):** Клик «Остановить генерацию» во время стриминга -> мгновенная остановка -> частичный ответ сохраняется.
5. **Сценарий 5 (Баланс и рефералы):** После ответа баланс уменьшается на стоимость токенов -> переключение баланса в 0.00 ₽ -> инпут блокируется с показом предупреждения -> клик по предупреждению открывает модалку рефералов -> кнопка копирует ссылку в буфер.
