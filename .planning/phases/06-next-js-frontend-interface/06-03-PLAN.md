<task id="06-03-01" wave="3">
<title>Клиентский хук useChatStream с ReadableStreamReader и AbortController</title>
<action>
1. Создать `frontend/src/hooks/useChatStream.ts`:
   - Поддерживает вызов `sendMessage(content: string)`:
     - Создает временное сообщение пользователя и плейсхолдер ответа ассистента в `useChatStore`.
     - Инициализирует `AbortController`, сохраняя ссылку в ref.
     - Выполняет `fetch('/api/v1/chat/stream', { method: 'POST', credentials: 'include', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ chat_id: activeChatId, model: selectedModel, content }), signal: controller.signal })`.
     - Получает `response.body.getReader()` (`ReadableStreamDefaultReader`).
     - Декодирует чанки через `TextDecoder('utf-8')`. Буферизует строки, разделяя по `\n\n`.
     - Разбирает события `data: {...}`:
       - `delta`: дописывает порцию текста к текущему сообщению ассистента в сторе.
       - `done`: завершает стриминг, сохраняет финальные токены и `cost_kopecks`, вызывает `applyDeduction(costKopecks)`.
       - `error`: отображает текст ошибки и завершает стрим.
   - Метод `abortStream()`: вызывает `controller.abort()`, сбрасывает флаг `isStreaming: false`.
   - Cleanup в `useEffect`: прерывает активный стрим при размонтировании компонента.
</action>

   - Рендеринг контента через `react-markdown` с плагином `remark-gfm` (БЕЗ `rehype-raw`). Кастомный рендерер для `code` с делегированием в `CodeBlock`.
   - Для сообщений ассистента: плашка со стоимостью (`0.03 ₽`) и токенами, мигающий курсор при незавершенном стриминге (`isStreaming && streamingMessageId === message.id`).
