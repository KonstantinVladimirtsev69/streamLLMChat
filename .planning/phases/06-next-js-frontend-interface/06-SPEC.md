# Phase 6: Next.js Frontend Interface — Specification

**Created:** 2026-09-18  
**Ambiguity score:** 0.08 (gate: ≤ 0.20)  
**Requirements:** 6 locked  

---

## Goal

Разработать полноценный, отзывчивый и визуально качественный веб-интерфейс чата на Next.js (App Router, Tailwind CSS, TypeScript), включающий приветственный экран с авторизацией через VK OAuth, сайдбар истории диалогов, окно чата с потоковым выводом ответов (SSE), подсветкой синтаксиса и Markdown, селектор моделей, виджет баланса с блокировкой при нуле и модальное окно реферальной программы.

---

## Background

В фазах 1–5 полностью реализован бэкенд на Go с API:
- Авторизация через VK OAuth (`/api/v1/auth/vk/login`, `/vk/callback`, `/mock`, `/me`, `/logout`) с выпуском JWT в HttpOnly cookie `auth_token`.
- Управление диалогами и сообщениями в MongoDB (`/api/v1/chats`, `/api/v1/chats/{id}`, `/messages`).
- Потоковый инференс routerai.ru со скользящим окном контекста и тарификацией (`/api/v1/chat/stream`).
- Каталог доступных моделей с тарифами (`/api/v1/models`).

В директории `frontend/` на текущий момент развернут базовый каркас Next.js 16 (React 19, Tailwind CSS v4) со стандартной дефолтной страницей. Пользовательский интерфейс отсутствует.

## Requirements

### R1. Приветственный экран и VK OAuth авторизация
Неавторизованный пользователь встречает презентационный экран сервиса с кнопкой входа через VK ID.
- **Current:** Отображается дефолтный шаблон Next.js.
- **Target:** При переходе на `/` неавторизованный пользователь видит экран с описанием сервиса (доступ к передовым LLM, стартовые 5 руб на баланс) и кнопкой «Войти через VK». Клик перенаправляет на `/api/v1/auth/vk/login` (или `/mock` в dev-режиме). При наличии валидной сессии (`GET /api/v1/auth/me`) происходит автоматический редирект в интерфейс чата `/chat`. Прямой переход неавторизованного на `/chat` перенаправляет на `/`.
- **Acceptance:** Неавторизованный пользователь не имеет доступа к переписке; после клика на кнопку входа и успешной аутентификации устанавливается сессия, открывается рабочее пространство чата с отображением имени и аватара пользователя.

### R2. Сайдбар управления диалогами
Боковая панель отображает список диалогов пользователя с возможностью создания, переключения и удаления.
- **Current:** Сайдбар отсутствует.
- **Target:** Панель запрашивает список чатов через `GET /api/v1/chats` и выводит их с сортировкой по `updated_at` (новые сверху). Кнопка «Новый диалог» вызывает `POST /api/v1/chats` и переключает на созданный чат. Активный чат визуально выделен. Для каждого чата доступны действия: удаление (с подтверждением) и отображение названия. На мобильных устройствах сайдбар скрывается в выезжающую шторку (drawer) с кнопкой-гамбургером.
- **Acceptance:** Список диалогов обновляется при создании и удалении; клик по чату загружает его историю; на экранах <768px сайдбар открывается по кнопке меню и автоматически закрывается при выборе чата или клике вне панели.

### R3. Чат с потоковым выводом (SSE), Markdown и подсветкой кода
Основная область переписки отображает сообщения с рендерингом Markdown и принимает ответы ассистента в реальном времени.
- **Current:** Окно переписки отсутствует.
- **Target:** История сообщений загружается через `GET /api/v1/chats/{id}/messages`. Отправка сообщения инициирует `POST /api/v1/chat/stream`. Ответ ассистента рендерится чанками (Server-Sent Events) в реальном времени с автоматической прокруткой вниз. Текст парсится как Markdown (заголовки, списки, таблицы). Блоки кода содержат плашку с названием языка и кнопку «Копировать код» (с индикацией галочки при копировании). Во время генерации кнопка отправки заменяется на «Остановить генерацию» (`AbortController`).
- **Acceptance:** Текст ассистента появляется по мере генерации без задержек; блоки кода форматируются с подсветкой синтаксиса; кнопка копирования помещает код в буфер обмена; клик «Остановить» мгновенно прекращает прием потока, сохраняя сгенерированный фрагмент.

### R4. Каталог и динамический селектор моделей
Пользователь может выбирать и менять LLM-модель как перед созданием чата, так и внутри открытого диалога.
- **Current:** Селектор моделей отсутствует.
- **Target:** Список моделей загружается из `GET /api/v1/models` с кэшированием на клиенте. В шапке чата или панели ввода доступен выпадающий список с поиском/фильтрацией моделей (название, провайдер, контекстное окно). Выбор модели в активном чате сохраняется и применяется для всех последующих сообщений диалога.
- **Acceptance:** Селектор отображает актуальные модели из API routerai.ru; смена модели в диалоге передает выбранный `model` в следующий запрос `POST /api/v1/chat/stream`.

### R5. Виджет баланса и блокировка при исчерпании средств
Интерфейс прозрачно информирует пользователя о состоянии счета в рублях и предотвращает отправку при нулевом балансе.
- **Current:** Баланс не отображается.
- **Target:** Текущий баланс запрашивается из `GET /api/v1/auth/me` и отображается в шапке (в формате `0.00 ₽`). После каждого завершенного стриминга баланс актуализируется. Если баланс пользователя равен 0.00 руб или сервер возвращает HTTP 402 `insufficient_balance`, поле ввода блокируется, а в интерфейсе отображается плашка с предупреждением и кнопка вызова реферального окна для пополнения бонусами (+2 руб).
- **Acceptance:** Баланс точно совпадает с данными БД; при нулевом балансе кнопка отправки неактивна, клик по предупреждению открывает реферальное окно.

### R6. Модальное окно реферальной программы
Модальное окно предоставляет пользователю ссылку для приглашения друзей и статистику бонусов.
- **Current:** Реферальный интерфейс отсутствует.
- **Target:** По клику на баланс или пункт меню профиля открывается модальное окно «Реферальная программа»: описание условий (+2 руб за каждого приглашенного), персональная ссылка (`https://domain/?ref=CODE`), кнопка «Скопировать ссылку» (с подтверждением в UI), счетчик приглашенных друзей и суммарный заработанный бонус.
- **Acceptance:** Модальное окно открывается и закрывается без перезагрузки страницы; реферальная ссылка успешно копируется в буфер обмена; корректно отображаются данные из профиля пользователя.

## Boundaries

### In Scope
- Приветственная посадочная страница (Landing) с кнопкой входа через VK ID.
- Авторизационный контекст и защита маршрутов (редирект `/chat` ↔ `/`).
- Полнофункциональный сайдбар истории диалогов с адаптивным drawer для мобильных устройств.
- Окно сообщений с потоковым выводом SSE, автопрокруткой и кнопкой прерывания генерации.
- Markdown-парсер с подсветкой синтаксиса кода и кнопкой копирования блоков кода.
- Селектор доступных моделей routerai.ru с возможностью смены на лету.
- Виджет баланса в рублях с автоматическим обновлением после ответов модели.
- Экран/плашка блокировки при исчерпании баланса (HTTP 402) с приглашением в реферальную программу.
- Модальное окно реферальной программы с копированием ссылки и отображением начислений.

### Out of Scope
- Подключение платёжных шлюзов (ЮKassa, Robokassa, СБП) — отложено до версии v2 (монетизация в v1 исключительно через приветственные 5 руб и реферальные 2 руб).
- Авторизация через Telegram, Google, email/пароль — в v1 строго VK OAuth.
- Загрузка вложений (изображений, PDF, файлов) — в v1 только текстовый чат.
- Голосовой ввод/вывод (Audio STT/TTS) — out of scope для v1.
- Редактирование и удаление отдельных сообщений внутри диалога — в v1 только удаление чата целиком.

## Constraints

- **Фреймворк:** Next.js 16 (App Router), React 19, TypeScript strict mode.
- **Стилизация:** Tailwind CSS v4 + дизайн-токены/CSS-переменные для гармоничной темы (темная тема по умолчанию, премиальный AI-style).
- **Безопасность:** Токены авторизации передаются исключительно через HttpOnly Cookie `auth_token` с флагом `SameSite=Lax`. Никаких секретов в `localStorage`.
- **Производительность:** Плавный стриминг текста без лагов DOM при длинных ответах, дебаунс поиска по моделям.
- **Модульность:** Соблюдение правила чистой архитектуры UI — размер компонентов не более 200–250 строк, вынос переиспользуемых примитивов в `shared/ui`.

## Acceptance Criteria

- [ ] Неавторизованный пользователь видит экран входа и не может отправить сообщение без авторизации
- [ ] Клик по «Войти через VK» запускает OAuth-редирект; успешная авторизация перенаправляет в `/chat`
- [ ] В сайдбаре отображается список диалогов; кнопка «Новый чат» создает пустой диалог
- [ ] Удаление диалога удаляет его из списка и переключает на соседний или пустой экран
- [ ] На смартфонах сайдбар открывается как выдвижная шторка и закрывается по выбору чата
- [ ] Сообщения ассистента появляются потоком в реальном времени через SSE
- [ ] Кнопка «Остановить генерацию» прерывает текущий SSE-поток без потери выведенного текста
- [ ] Markdown корректно форматирует списки, таблицы и блоки кода
- [ ] Блоки кода содержат плашку с языком и работающую кнопку «Копировать код»
- [ ] Селектор моделей отображает список из `/api/v1/models` и позволяет переключать модель в активном чате
- [ ] Текущий баланс в рублях отображается в шапке и уменьшается после генерации ответа
- [ ] При нулевом балансе поле ввода блокируется с выводом предупреждения и кнопки реферального окна
- [ ] Модальное окно реферальной программы открывается по клику и копирует уникальную ссылку в буфер
- [ ] `npx tsc --noEmit` и `npm run build` выполняются с 0 ошибок
