<task id="06-01-02" wave="1">
<title>Приветственный лендинг, Dev Mock вход и серверный middleware защиты маршрутов</title>
<action>
1. Создать `frontend/src/components/landing/HeroSection.tsx`:
   - Заголовок сервиса, презентация возможностей общения с лучшими LLM через routerai.ru.
   - Плашка с приветственным бонусом: "5.00 ₽ на баланс при регистрации".
   - Кнопка авторизации "Войти через VK ID" со ссылкой на `/api/v1/auth/vk/login`.
   - Кнопка "Быстрый вход (Dev Mock)" со ссылкой на `/api/v1/auth/mock` (отображается только при `process.env.NODE_ENV === 'development'`).
   - Использование токенов Modern AI Dark и компонентов в стиле скетча 001.
2. В `frontend/src/app/page.tsx`:
   - Использовать `HeroSection` в качестве корневого экрана для неавторизованных пользователей.
3. Создать `frontend/src/middleware.ts`:
   - Проверять наличие HttpOnly cookie `auth_token` в запросе.
   - Если пользователь без куки запрашивает `/chat` (или подмаршруты `/chat/*`) -> `NextResponse.redirect` на `/`.
   - Если пользователь с кукой `auth_token` открывает `/` -> `NextResponse.redirect` на `/chat`.
   - Настроить `matcher: ['/', '/chat/:path*']`.
</action>
