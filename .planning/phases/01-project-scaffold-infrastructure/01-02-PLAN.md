<task type="auto">
  <name>Task 2: Создание docker-compose.yml для PostgreSQL 18 и MongoDB 8</name>
  <files>docker-compose.yml</files>
  <read_first>.env.example, .planning/phases/01-project-scaffold-infrastructure/01-SPEC.md</read_first>
  <action>
    Создать корневой `docker-compose.yml` (формат Compose v2) с двумя сервисами:
    1. `postgres`:
       - image: `postgres:18-alpine` (с fallback на `postgres:latest` если 18-alpine недоступен)
       - container_name: `llm_postgres`
       - restart: unless-stopped
       - environment: POSTGRES_USER=${POSTGRES_USER:-postgres}, POSTGRES_PASSWORD=${POSTGRES_PASSWORD:-postgres}, POSTGRES_DB=${POSTGRES_DB:-llm_chat}
       - ports: `${POSTGRES_PORT:-5432}:5432`
       - volumes: `postgres_data:/var/lib/postgresql/data`
       - healthcheck: `test: ["CMD-SHELL", "pg_isready -U postgres -d llm_chat"]`, interval: 5s, timeout: 5s, retries: 5
    2. `mongodb`:
       - image: `mongo:8.0` (с fallback на `mongo:latest`)
       - container_name: `llm_mongodb`
       - restart: unless-stopped
       - environment: MONGO_INITDB_DATABASE=${MONGO_DB:-llm_chat}
       - ports: `${MONGO_PORT:-27017}:27017`
       - volumes: `mongo_data:/data/db`
       - healthcheck: `test: ["CMD-SHELL", "mongosh --eval 'db.adminCommand(\"ping\")' || exit 1"]`, interval: 5s, timeout: 5s, retries: 5
    - Задать именованные volumes в секции `volumes:`: `postgres_data:` и `mongo_data:`.
  </action>
  <acceptance_criteria>
    - docker-compose.yml содержит сервисы "postgres" и "mongodb"
    - docker-compose.yml определяет volumes "postgres_data" и "mongo_data"
    - `docker compose config -q` завершается с кодом 0
  </acceptance_criteria>
  <verify>
    <automated>docker compose config -q</automated>
    <fails_when>non-zero exit</fails_when>
  </verify>
