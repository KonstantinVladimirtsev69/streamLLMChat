<task id="04-02-01" wave="2">
<title>Создание ChatHandler с эндпоинтами GetModels и StreamChat (SSE)</title>
<action>
1. Создать `backend/internal/server/handler/chat.go`:
   - Структура `ChatHandler` с зависимостью `provider llm.LLMProvider` и `modelCache *llm.ModelCache`.
   - Конструктор `NewChatHandler(provider llm.LLMProvider, modelCache *llm.ModelCache) *ChatHandler`.
   - Метод `GetModels(w http.ResponseWriter, r *http.Request)`:
     - Получает список моделей через `modelCache.GetModels(r.Context())`.
     - Возвращает JSON `{"models": [...]}` с HTTP 200.
   - Метод `StreamChat(w http.ResponseWriter, r *http.Request)`:
     - Парсит входящий JSON `model.ChatCompletionRequest`. Если `Model` или `Messages` пустые, возвращает HTTP 400.
     - Проверяет поддержку `http.Flusher`. Если не поддерживается, возвращает HTTP 500.
     - Настраивает `http.ResponseController(w)`: вызывает `rc.SetWriteDeadline(time.Time{})` для снятия таймаута записи на время стрима.
     - Устанавливает заголовки ответа:
       - `Content-Type: text/event-stream`
       - `Cache-Control: no-cache`
       - `Connection: keep-alive`
       - `X-Accel-Buffering: no`
     - Вызывает `flusher.Flush()`.
     - Запускает `provider.StreamChat(r.Context(), req)`:
       - В цикле читает `StreamEvent` из канала.
       - Форматирует каждое событие как `data: <JSON>\n\n` и пишет в `w`.
       - Вызывает `flusher.Flush()` после каждого события.
       - Корректно завершает стрим при закрытии канала или отмене `r.Context()`.
</action>

<fails_when>non-zero exit, or FAIL</fails_when>
</verify>
<done>ChatHandler создан со снятием таймаутов через ResponseController и отдачей SSE-событий.</done>
</task>
