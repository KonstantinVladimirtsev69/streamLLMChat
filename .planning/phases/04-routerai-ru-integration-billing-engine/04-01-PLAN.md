<task id="04-01-01" wave="1">
<title>Модели данных LLM и модуль расчета стоимости токенов с тестированием math.Ceil</title>
<action>
1. Создать `backend/internal/model/llm.go` с типами:
   - `LLMModel`: `ID string`, `Name string`, `Description string`, `PromptPricePer1M float64`, `CompletionPricePer1M float64`, `ContextLength int` (с json-тегами).
   - `ChatMessage`: `Role string` (`user`, `assistant`, `system`), `Content string`.
   - `ChatCompletionRequest`: `Model string`, `Messages []ChatMessage`, `Stream bool`.
   - `StreamEventType string` (`delta`, `done`, `error`).
   - `TokenUsage`: `PromptTokens int`, `CompletionTokens int`, `TotalTokens int`, `CostKopecks int64`.
   - `StreamEvent`: `Type StreamEventType`, `Content string`, `Usage *TokenUsage`, `Error string`.
2. Создать `backend/internal/llm/pricing.go` с функцией:
   - `CalculateTokenCost(promptTokens, completionTokens int, promptPricePer1M, completionPricePer1M float64) int64`:
     Вычисляет стоимость в копейках по формуле: `math.Ceil(((float64(promptTokens) * promptPricePer1M + float64(completionTokens) * completionPricePer1M) / 1000000.0) * 100.0)`.
     Если promptTokens <= 0 и completionTokens <= 0, возвращает 0.
3. Создать `backend/internal/llm/pricing_test.go`:
   - Проверить 0 токенов -> 0 копеек.
   - Проверить дробные части: при 1 токене с ценой 50 руб/1M стоимость должна округляться до 1 копейки (`math.Ceil`).
   - Проверить стандартные расчеты: 1000 prompt (100 руб/1M) + 500 completion (200 руб/1M) = 10 коп + 10 коп = 20 коп.
</action>

<automated>go -C backend test -v ./internal/llm/...</automated>
<fails_when>non-zero exit, or FAIL</fails_when>
</verify>
<done>Модели определены, расчет стоимости токенов строго покрыт unit-тестами с проверкой math.Ceil.</done>

<task id="04-01-02" wave="1">
<title>Интерфейс LLMProvider, клиент RouterAIClient и автономный MockLLMProvider (D-01)</title>
<action>
1. Создать `backend/internal/llm/provider.go` (D-01):
   - Интерфейс `LLMProvider`:
     - `GetModels(ctx context.Context) ([]model.LLMModel, error)`
     - `StreamChat(ctx context.Context, req model.ChatCompletionRequest) (<-chan model.StreamEvent, <-chan error)`
2. Создать `backend/internal/llm/routerai.go`:
   - Конструктор `NewRouterAIClient(apiKey, baseURL string, httpClient *http.Client) *RouterAIClient`.
   - Метод `GetModels(ctx context.Context)`: отправляет `GET /models` с заголовком `Authorization: Bearer <apiKey>`, парсит OpenAI response `{"data": [...]}` и извлекает модели и тарифы (при отсутствии тарифов в API использует fallback-тарифы).
   - Метод `StreamChat(ctx context.Context, req model.ChatCompletionRequest)`:
     - Делает `POST /chat/completions` с `stream: true`, `stream_options: {"include_usage": true}`.
     - Читает SSE поток (`bufio.Reader` построчно `data: ...`).
     - Парсит дельты `{"choices":[{"delta":{"content":"..."}}]}` и эмитит `StreamEvent{Type: "delta", Content: text}` в канал.
     - При получении финального чанка с `"usage"` или перед закрытием вычисляет `TokenUsage` с `CalculateTokenCost` и эмитит `StreamEvent{Type: "done", Usage: &usage}`.
     - Защищает от утечки goroutine при отмене контекста `ctx.Done()`.
3. Создать `backend/internal/llm/mock.go`:
   - Конструктор `NewMockLLMProvider()` с настраиваемыми ответами:
     - `SetDefaultReply(reply string)`
     - `SetChunkDelay(d time.Duration)`
     - `SetSimulatedUsage(promptTokens, completionTokens int)`
   - Имплементация `GetModels` возвращает предопределенный список популярных моделей (`deepseek/deepseek-chat`, `openai/gpt-4o-mini`, `anthropic/claude-3-5-sonnet`).
   - Имплементация `StreamChat` стримит текст по словам в канал событий и завершает событием `done` с токенами и стоимостью.
4. Создать `backend/internal/llm/mock_test.go`:
   - Проверить работу `MockLLMProvider` на получение моделей и чтение полного стрима чанков.
</action>

<task id="04-01-03" wave="1">
<title>In-memory TTL кэш каталога моделей со статическим fallback (D-02)</title>
<action>
1. Создать `backend/internal/llm/cache.go` (D-02):
   - Структура `ModelCache`:
     - `provider LLMProvider`
     - `ttl time.Duration` (по умолчанию 15 минут)
     - `cachedModels []model.LLMModel`
     - `lastUpdated time.Time`
     - `mu sync.RWMutex`
   - Метод `GetModels(ctx context.Context) ([]model.LLMModel, error)`:
     - RLock: если кэш актуален (`time.Since(lastUpdated) < ttl` и `len(cachedModels) > 0`), возвращает кэшированные модели.
     - Lock: делает запрос `provider.GetModels(ctx)`. При успехе обновляет кэш и `lastUpdated`.
     - При ошибке провайдера: если в кэше уже есть данные, возвращает их; если кэш пуст — возвращает встроенный статический список популярных моделей (`GetDefaultStaticModels()`), предотвращая отказ платформы.
2. Создать `backend/internal/llm/cache_test.go`:
   - Тест на возврат кэшированных данных без повторного вызова провайдера.
   - Тест на обновление кэша после истечения TTL.
   - Тест на возврат статического fallback при ошибке провайдера на пустом кэше.
</action>
