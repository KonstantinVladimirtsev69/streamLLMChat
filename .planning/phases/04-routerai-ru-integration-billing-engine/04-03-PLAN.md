<task id="04-03-01" wave="3">
<title>Расширение BalanceRepository методом DeductUsage с поддержкой овердрафта (D-05)</title>
<action>
1. В `backend/internal/repository/repository.go`:
   - Добавить в интерфейс `BalanceRepository`:
     `DeductUsage(ctx context.Context, userID int64, amount int64, txType model.TransactionType, refID *string, description string) (*model.Balance, error)`
2. В `backend/internal/repository/postgres/balance.go` (D-05):
   - Реализовать метод `DeductUsage`:
     - Проверить `amount <= 0` (при `amount == 0` возвращать текущий баланс без записи в журнал).
     - Выполнить атомарный SQL запрос без ограничения `>= amount`:
       ```sql
       UPDATE balances
       SET amount_kopecks = amount_kopecks - $1,
           updated_at = NOW()
       WHERE user_id = $2
       RETURNING amount_kopecks, updated_at;
       ```
     - Записать транзакцию в `balance_transactions`:
       ```sql
       INSERT INTO balance_transactions (user_id, amount_kopecks, balance_after_kopecks, type, reference_id, description, created_at)
       VALUES ($1, $2, $3, $4, $5, $6, NOW());
       ```
       где `amount_kopecks = -amount` (отрицательное значение дебета).
3. Добавить тесты в `backend/internal/repository/postgres/balance_test.go`:
   - Проверить списание при достаточном балансе.
   - Проверить уход баланса в минус (овердрафт) при сумме списания больше текущего баланса.
   - Проверить корректность записи отрицательного дебета в `balance_transactions`.
</action>

<task id="04-03-02" wave="3">
<title>Создание сервиса биллинга BillingService</title>
<action>
1. Создать `backend/internal/service/billing.go`:
   - Интерфейс `BillingService`:
     - `CanGenerate(ctx context.Context, userID int64) (bool, int64, error)`
     - `ChargeTokens(ctx context.Context, userID int64, usage model.TokenUsage, modelID string, refID *string) (*model.Balance, error)`
   - Реализация `billingService`:
     - `CanGenerate`: проверяет `balanceRepo.GetByUserID(ctx, userID)`. Возвращает `true, balance.AmountKopecks, nil` если `amount_kopecks > 0`.
     - `ChargeTokens`: если `usage.CostKopecks <= 0`, возвращает текущий баланс; иначе вызывает `balanceRepo.DeductUsage(ctx, userID, usage.CostKopecks, model.TxTokenCharge, refID, fmt.Sprintf("LLM token charge (%s): %d tokens", modelID, usage.TotalTokens))`.
2. Создать `backend/internal/service/billing_test.go`:
   - Тест `CanGenerate` при положительном, нулевом и отрицательном балансе.
   - Тест `ChargeTokens` с созданием транзакции `token_charge`.
