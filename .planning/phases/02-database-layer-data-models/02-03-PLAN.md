<task id="02-03-01" wave="2">
<title>Реализация пула pgxpool и контекстного TxManager</title>
<instruction>
1. Создать `backend/internal/database/postgres.go`:
   - Функция `NewPostgresPool(ctx context.Context, databaseURL string) (*pgxpool.Pool, error)` с настройкой пула соединений.
2. Создать `backend/internal/database/tx_manager.go`:
   - Интерфейс `DBTX` (`Exec`, `Query`, `QueryRow`).
   - Ключ контекста `txKey` и функции `InjectTx(ctx, tx)`, `ExtractTx(ctx) (pgx.Tx, bool)`.
   - Интерфейс `TxManager` и реализация `pgxTxManager`:
     - Метод `WithinTransaction(ctx context.Context, fn func(ctx context.Context) error) error`:
       - Начинает `pool.Begin(ctx)`
       - Вызывает `fn(InjectTx(ctx, tx))`
       - В случае паники или ошибки вызывает `tx.Rollback(ctx)`
       - В случае успеха вызывает `tx.Commit(ctx)`
</instruction>

<task id="02-03-02" wave="2">
<title>Реализация PostgreSQL репозиториев для пользователей и балансов</title>
<instruction>
1. В `backend/internal/repository/repository.go` объявить интерфейсы:
   - `UserRepository`: `GetByID(ctx, id)`, `GetByVKID(ctx, vkID)`, `GetByRefCode(ctx, code)`, `Create(ctx, user)`.
   - `BalanceRepository`: `GetByUserID(ctx, userID)`, `AddBonus(ctx, userID, amount, txType, desc)`, `Deduct(ctx, userID, amount, txType, refID, desc)`, `GetTransactions(ctx, userID, limit, offset)`.
2. В `backend/internal/repository/postgres/user.go` реализовать `UserRepository`.
3. В `backend/internal/repository/postgres/balance.go` реализовать `BalanceRepository`:
   - `Deduct`: атомарный запрос `UPDATE balances SET amount_kopecks = amount_kopecks - $1, updated_at = NOW() WHERE user_id = $2 AND amount_kopecks >= $1 RETURNING amount_kopecks`. Если 0 строк обновлено — возвращать `model.ErrInsufficientBalance`. При успехе создавать запись в `balance_transactions`.
   - `AddBonus`: `UPDATE balances SET amount_kopecks = amount_kopecks + $1, updated_at = NOW() WHERE user_id = $2 RETURNING amount_kopecks` + запись в `balance_transactions`.
</instruction>
