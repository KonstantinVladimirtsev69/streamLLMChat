<task id="02-02-01" wave="1">
<title>Подключение mongo-driver/v2 и определение моделей MongoDB</title>
<instruction>
1. Добавить `go.mongodb.org/mongo-driver/v2` в `backend/go.mod`.
2. Создать `backend/internal/model/chat.go`:
   - Структура `Chat`: `ID` (primitive.ObjectID `bson:"_id,omitempty" json:"id"`), `UserID` (int64 `bson:"user_id" json:"user_id"`), `Title` (string `bson:"title" json:"title"`), `Model` (string `bson:"model" json:"model"`), `CreatedAt` (time.Time `bson:"created_at" json:"created_at"`), `UpdatedAt` (time.Time `bson:"updated_at" json:"updated_at"`).
3. Создать `backend/internal/model/message.go`:
   - Структура `Message`: `ID` (primitive.ObjectID), `ChatID` (primitive.ObjectID), `UserID` (int64), `Role` (string: "user" | "assistant" | "system"), `Content` (string), `PromptTokens` (int), `CompletionTokens` (int), `TotalTokens` (int), `CostKopecks` (int64), `CreatedAt` (time.Time).
</instruction>

</verify>
</task>

<task id="02-02-02" wave="1">
<title>Реализация клиента MongoDB и создания составных индексов</title>
<instruction>
1. Создать `backend/internal/database/mongo.go`:
   - Функция `NewMongoClient(ctx context.Context, uri string) (*mongo.Client, error)` с настройкой таймаута и пула соединений.
   - Функция `EnsureIndexes(ctx context.Context, db *mongo.Database) error`:
     - Создание составного индекса в коллекции `chats`: `{ user_id: 1, updated_at: -1 }`.
     - Создание составного индекса в коллекции `messages`: `{ chat_id: 1, created_at: 1 }`.
2. Написать unit-тест `backend/internal/database/mongo_test.go` для проверки спецификации индексов и валидации URI.
</instruction>
