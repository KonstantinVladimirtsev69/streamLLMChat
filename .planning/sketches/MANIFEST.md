# Sketch Manifest

## Design Direction
**Modern AI Dark** (стиль Claude, Linear, Vercel) — глубокая ночная космическая палитра (`#090a0f`), полупрозрачные карточки с размытием (frosted glassmorphism `rgba(20,23,36,0.72)`), ультратонкие субпиксельные границы (`rgba(255,255,255,0.08)`), неоновые фиолетово-индиго акценты, прецизионная моноширинная типографика для кода и информационных индикаторов токенов.

## Reference Points
- **Claude.ai / ChatGPT** — чистая центрированная колонка переписки, фокус на тексте и плавающий нижний инпут.
- **Linear / Raycast** — ультра-отзывчивые селекторы, компактные сайдбары, матовые модальные окна и ховер-эффекты.
- **Cursor / v0.dev** — блоки кода с заголовком языка, кнопкой копирования и удобным переключением моделей прямо в процессе работы.
