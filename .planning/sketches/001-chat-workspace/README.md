# Sketch 001: Chat Workspace Layout

## Design Question
Какая структура рабочего пространства (layout) создает наиболее комфортный и интуитивный опыт взаимодействия с LLM в рамках концепции Modern AI Dark?

## How to View
Открыть в браузере файл:
`file:///c:/Projects/stream/streamLLMChat/.planning/sketches/001-chat-workspace/index.html`

## Variants
- **Вариант A: Classic Clean (в стиле Claude / ChatGPT)**
  - Фиксированный сайдбар диалогов слева со списком сессий и кнопкой «Новый диалог».
  - Верхняя панель: селектор модели + интерактивный виджет баланса (`5.00 ₽` с кнопкой рефералов).
  - Центрированная лента сообщений шириной ~800px для максимальной читаемости.
  - Плавающий нижний контейнер ввода с индикатором оценки стоимости токенов.

- **Вариант B: Floating Minimalist (в стиле Linear / Raycast)**
  - Ультракомпактный узкий rail с иконками слева.
  - Парящий комбинированный док снизу со встроенным дропдауном модели и балансом.
  - Разреженный холст сообщений с акцентом на контент.

- **Вариант C: Pro Split Canvas (в стиле Cursor / IDE)**
  - Левый сайдбар диалогов + центральный чат.
  - Правая панель телеметрии (Inspector): детальные характеристики активной модели (контекст, цены за 1K токенов), остаток баланса и блок реферальной программы.

## Interactive Features in Sketch:
1. **Переключение вариантов:** Верхняя панель навигации (A / B / C).
2. **Симуляция стриминга:** Введите сообщение или нажмите «Отправить» — текст печатается по частям, кнопка отправки сменяется на «Остановить», после генерации баланс уменьшается.
3. **Блоки кода:** Кнопка «Копировать» в правом верхнем углу блока кода меняет текст на `✓ Скопировано!` и копирует код в буфер.
4. **Модалка рефералов:** Кликните по виджету баланса или кнопке «🎁 Рефералы» в шапке — открывается модальное окно с персональной ссылкой и кнопкой копирования.
5. **Тестирование нулевого баланса:** Кнопка «Переключить баланс 0₽ / 5₽» демонстрирует предупреждение и блокировку поля ввода.
6. **Viewport-тулбар:** В правом нижнем углу кнопки переключения ширины экрана (Full, 1280px, 768px, 375px).
